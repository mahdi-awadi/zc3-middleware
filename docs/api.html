ZKTeco C3 Access-Control Middleware

A REST + Server-Sent-Events API in front of a ZKTeco C3 access panel. Manage cards and access rules, open doors, read live status, and stream access events. The panel makes access decisions locally — the middleware never sits in the unlock path.

Validated on C3-200 · fw 5.4.3.2001 Base URL http://localhost:8080 Auth Bearer API_KEY

Authentication

When API_KEY is set, every endpoint except /healthz and /metrics requires Authorization: Bearer <API_KEY>. If unset, auth is disabled (dev only).

Errors

Errors return {"error":"…"}. 400 = bad request, 401 = unauthorized, 502 = the panel was reached but the operation failed or writes are disabled.

Methods: GET POST PUT DELETE · Writes (POST/DELETE /cards) require ALLOW_WRITES=true
