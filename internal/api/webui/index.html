Find panels

The same method as AxTraxNG's "Find Panels", run from this middleware.

1. Adapter on the network
Sends www.usr.cn to UDP 48899, as a broadcast and to the configured host. USR adapters (USR-W610) answer with IP and MAC.
Not run yet.
2. RS-485 port
TCP to PANEL_ADDR, the adapter's serial port (9600 8N1, to L1/L2 on the panel).
Not run yet.
3. Ask every bus address
6A RequestFirmVer to addresses 1–32 (DIP switches 4–8). A panel answers EB with its firmware.
Not run yet.

How access works

          
The panel opens the turnstile by itself for every enrolled card, on the doors you tick.

          
To limit a role to certain hours (for example students may enter 07:00–07:30), switch to Advanced and use Access control › Access rules.

          
Card number = the number printed on the card or shown when it is swiped (facility and card together, e.g. 123/4660 = 8065588).

About

      
Access Console

        
Menu layout follows AxTraxNG (menu bar, tree, event log, status bar) and ZKAccess 3.5 (Personnel, Device, Access control, Reports, System and its step-by-step start page). Simple mode shows the everyday items; Advanced adds access rules, the event log panel, raw data and device tools.
