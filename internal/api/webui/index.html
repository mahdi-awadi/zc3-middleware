Find the door controller

The same steps as AxTraxNG's "Find Panels", run live from this middleware.

1 · Adapter on the network

Sends www.usr.cn to UDP port 48899, as a broadcast and to the configured host. Every USR serial adapter (USR-W610) answers with its IP and MAC.

Not run yet.

2 · Open its RS-485 port

Connects over TCP to PANEL_ADDR, the adapter's transparent serial port (9600 8N1, wired to L1/L2 of the panel).

Not run yet.

3 · Ask every bus address

Sends 6A RequestFirmVer to bus addresses 1–32 (the panel's DIP switches 4–8). A panel answers EB with its firmware name.

Not run yet.
